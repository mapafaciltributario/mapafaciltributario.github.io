PROJETO ORIGINAL LOVABLE - TanStack Start / React / TypeScript

Os arquivos package.json, vite.config.ts e outros estao na RAIZ deste ZIP, sem pasta envolvente.
As pastas src/ e public/ sao essenciais para o funcionamento e NAO podem ser removidas sem reescrever a aplicacao.
Este projeto nao possui index.html estatico na fonte: a pagina e gerada pelo framework durante o build.

Para hospedar: importar o repositorio GitHub diretamente na Vercel, instalar dependencias e executar npm run build.
Confirmar compatibilidade do preset Nitro com a plataforma e configurar as variaveis CAKTO_CLIENT_ID, CAKTO_CLIENT_SECRET, CAKTO_OFFER_ID_BASICO e CAKTO_WEBHOOK_SECRET conforme o projeto.
Nao publicar como GitHub Pages puro: ele nao executa funcoes de pagamento.
Nao colocar chaves no codigo ou em arquivos publicos.
Antes de vender, validar build, Pix, status e webhook e a entrega do produto.
